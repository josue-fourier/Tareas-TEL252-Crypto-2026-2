# Tareas-TEL252-Crypto-2026-2

## Descripción

Repositorio de tareas para la asignatura de criptografía (TEL252) UTFSM.

## Estructura

Cada tarea presentará la siguiente estructura, siendo N el número de la tarea:

```bash
/Tarea_N/ 
    parte1.ipynb
    parte2.ipynb
    parte3.ipynb
    parte4.ipynb
/TareaN.ipynb
```

En donde TareaN.ipynb es la compilación de todas las partes en Tarea_N/, completando así la tarea.
